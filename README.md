# 📞 Calling Solution

**Calling Solution** is a cross-platform mobile and web application built using **Ionic + Angular**.  
It provides a complete calling management dashboard with features like call tracking, lead management, and activity monitoring.

## 🚀 Getting Started
Follow these steps to set up and run the project locally.

Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (LTS version recommended)
- [Ionic CLI](https://ionicframework.com/docs/cli)
- npm install -g @ionic/cli

1)git clone https://github.com/poojasg1998/callingSollutions.git
2)cd callingSollutions
3)npm install
4)run application:- ionic serve
5)Once the app starts, open your browser and go to:
👉 http://localhost:8100
